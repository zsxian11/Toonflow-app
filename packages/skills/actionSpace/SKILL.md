# 动作与空间预演

文字很难锁死空间关系；视频每切一镜都会重新想象房间，左右与门窗容易穿帮。难镜先定**看得懂的物理事件链**，再用 **3D 导演台**导出白模视频作参考，最后才烧成片。细则见 [打斗与空间写法](references/fightCraft.md)、[白模职责声明](references/previsDuty.md)。

本技能只交付可复制的提示词、资产清单与预演步骤；不声称已出图或已出视频。画布操作遵循 canvas；默认制作顺序遵循 production。

## 何时启用

- production 判定为难镜：打斗、追逐、多层楼梯/廊道、需严格左右关系的走位。
- 用户点名打戏优化、空间穿帮、白模预演、导演台参考视频。

对白、单人静态、无复杂走位的片段不要套本技能，也不强制导演台。

## 分步交付

每次回复默认只完成一步；用户说「一次全给」时按序一次输出。

1. **方案**：戏核、对阵、场地（方位参照与 ≤3 地标）、分段与节拍、段末可读姿态、资产清单（C/W/S ID）；标明哪一段起改用战损/换装状态图。
2. **资产提示词**：角色/兵器/场景等；锁定卡 8–12 短语；战损版单独计项。若项目已有 production / novelPipeline 状态变体，复用其 `adoptedPath` / `states[].id`，不另造冲突 id。
3. **分段分镜**：每段一个可投喂代码块（基础设定、时间轴、硬约束、负面）；第 2 段起写【承接】；「本段上传」只列本段状态图（战损出现后下一段替换完好态）。
4. **预演与投喂**：导演台白模 → 导出视频节点 → 连视频生成节点 → 提示词写入 [职责声明](references/previsDuty.md) → 展示费用并等确认。

## 最高原则

先把这场戏写成一条物理事件链：谁、从哪里、沿什么路线、用什么打向/走向哪里、对方怎么应、碰到之后力往哪去、最后停在什么状态。镜头与特效只用来证明这条链。形容词堆砌不能代替事件链。

方位：角色肢体与持握用「角色自身左/右」；画面方向用「画左/画右」；末态与【承接】用地标和角色自身方向，不用画左画右。

## 预演支线（难镜必做）

1. 读本技能与 [previsDuty](references/previsDuty.md)。
2. 为片段视频生成节点 `setConfig({ previsRequired: true })`；分镜表可写 `previsStatus: pending`。
3. 建或打开 `director3dNode`，`setExportTarget` 指向该视频生成节点（或导出前单选它）；用文字生成人偶走位与运镜。
4. 用户确认预演后导出 MP4（尽量自动连边）；关键帧 PNG 可作构图参考。写回 `previsVideoPath` 与 `previsStatus: ready`。
5. 模式须支持参考视频；再连角色、场景等资产图。`setPrompt` 含 [职责声明](references/previsDuty.md)；核对 `{{ref N}}`。
6. 展示方案与费用：`previsRequired` 且无参考视频时不得请求生成授权。用户同意后再 `generateVideo`（节点层也会拒绝无参考视频的难镜）。

Blender 机位烘焙工具只做 360 空镜，不替代本支线的人偶动作预演。
