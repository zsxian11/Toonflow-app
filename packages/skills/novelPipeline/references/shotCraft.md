# 分镜与运镜（Comfy 制片用）

精简自镜头设计常识，供 `novelPipeline` 写 `shotSheet` 时使用。目标是可执行的画面意图，不是文学评论。

## 景别

- 大远景 / 远景：交代环境与方位
- 全景：人物全身与动作关系
- 中景：腰以上表演与互动
- 近景 / 特写：表情、道具、关键信息
- 避免连续三镜同景别无动机

## 运镜

用明确动词：固定、推、拉、摇、移、升、降、环绕、跟随。写清起止动机（揭示、压迫、陪伴、眩晕等）。单段内运镜不超过一个主意图，除非用户要求复杂镜头。

## 转场

- 直切：节奏快、信息紧
- 淡入淡出：时间跳跃或情绪落幅
- 叠化：回忆、梦境、主题呼应
- 匹配剪辑：形状/动作衔接（须在 action 中写清匹配点）

写入 `transitionIn` / `transitionOut`，并在 `prompts.comfy` 用自然语言点明，避免只写术语缩写。

## 连续性

- 同一场轴线、服装、时段与 `characters` 已采用形象一致
- 对白与口型需求在 `dialogue` / `audio` 标明
- 段与段之间交代空间如何接上，防止跳跃穿帮

## 分段

遵守 `episodes.json` 的 `segmentCount` 与 `targetDurationSec`；单段时长不超过当前 Comfy 视频工作流在设置中声明的能力。先保剧情完整，再均分时长。
